# 案件说明报纸 UI

`newspaper_modules.png` 是案件进入前说明界面使用的透明模块图。Godot 通过 `AtlasTexture` 在运行时裁切报头、报纸正文、现场照片、回形针、提示纸条和深色按钮；标题、正文、案件提示与按钮文字仍由控件绘制，便于后续修改和本地化。

`reference.png` 保留用户提供的完整效果参考。实际界面逻辑位于 `scripts/first_case_flow_ui.gd`，所有案件共用同一版式，显示内容继续读取各案件 JSON 中的 `briefing` 字段。

结案界面同样使用此图集，但采用独立的结案特刊版式：报头及结果标题置顶，左栏分为复原记录、后续调查，右栏为档案照片，底部为拍照及返回操作。内容读取 `completion` 字段；拍照前后继续使用原有流程信号。1180×680 版面随较小窗口等比缩放。`tests/smoke_settlement_newspaper.gd` 验证文字容纳、窗口适配、真实按钮点击与拍照成功/失败状态，并输出结案预览截图；测试不写入玩家存档或相册。

案件资料阅读界面也使用此图集：`scripts/case_archive_view.gd` 负责纸张、目录、照片与纯文字版式；`scripts/case_file_ui.gd` 负责分类、资料选择与线索解锁。布局以 1600×900 为基准等比例适配窗口，照片等比完整显示。纯文字资料隐藏照片和图片说明区域，正文使用整张纸的宽度。对应已确认的 SVG 设计稿位于 `design/case_files_newspaper/`。
