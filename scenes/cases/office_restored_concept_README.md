# 第一案 · 复原办公室概念场景

打开 `res://scenes/cases/office_restored_concept.tscn`，按 F6 运行当前场景。

独立、静态的 3D 场景。没有新增运行脚本、调查热点、家具摆放逻辑或操作界面；原项目的全局自动加载系统仍会随 F6 启动。没有修改默认启动场景，也没有覆盖原案件和工作室。

按概念图搭建电脑桌与椅子、紧邻右侧的米白矮柜、左侧高柜与饮水机、右侧打印机及照片、百叶窗、开门、盆栽、公告板和桌面陈设。高柜中层文件夹从左到右为红、灰、米色。地面有独立的椅轮磨痕和水印网格。

采用现有漫画着色器的分段明暗、黑色描边及实时灯光阴影。所有物件直接保存在节点树中，可在编辑器中调整。导入的椅子使用本地网格节点，避免嵌套模型重复保存。

构建工具：`res://tools/build_office_restored_concept.gd`（继承已有工具的几何构建函数；重新执行会重建本场景，手动编辑后不要直接重跑）。

验证工具：`res://tools/render_office_restored_concept.gd`，包含编辑器模式加载、保存重载、文件夹顺序检查和实际渲染。截图：`res://tests/office_restored_concept_preview.png`。
